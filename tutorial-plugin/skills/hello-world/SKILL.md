# `hello-world`

Skill de ejemplo mínimo para el plugin `tutorial-plugin`.

Comportamiento:

- Entrada: `hello-world` o `hello-world <nombre>`.
- Respuesta: mensaje amistoso de ejemplo ("Hola, <nombre>! Esto es un plugin de tutorial.").

Uso en tutorial: muestra cómo estructurar un skill y su `SKILL.md`. Para convertirlo en funcional, añadir un handler que acepte la entrada del usuario y devuelva la respuesta formateada.
